# Atelier Brown - Interior Design Landing Page
Static site: HTML + CSS + vanilla JS. Open index.html (or use VS Code Live Server). No build step.

Before launch:
- js/main.js -> CONFIG.whatsappNumber: your WhatsApp number, digits only with country code (e.g. 919812345678). The enquiry form opens WhatsApp with the details filled in.
- js/main.js -> CONFIG.social: add profile URLs to activate footer icons.
- index.html -> contact map: replace the address text after q= (iframe src) and query= (Open in Google Maps link).
- Replace placeholder brand name, address, phone, email and hours.
- Photos are hotlinked from Unsplash; download and host locally for production.

Sections: Home, About, Services, Gallery, Statement, Why, How we work (process), Contact. The floating WhatsApp button and the enquiry form both use CONFIG.whatsappNumber.
